# 내 캘린더 — 노션 스타일 캘린더 + 할 일 (1단계 MVP)

혼자 쓰는 캘린더 + 할 일 관리 웹앱입니다. 데이터는 브라우저(IndexedDB)에만 저장됩니다. 로그인이나 서버는 없습니다.

## 쓰는 방법 (3가지 중 하나)

### A. 설치 없이 브라우저로 쓰기 (추천, 회사 PC)
**👉 https://jeong3165.github.io/my-calendar/** 를 엽니다.
- Node.js 설치나 스크립트 실행이 필요 없어서 회사 보안 정책에 걸리지 않습니다.
- 인터넷이 끊겨도 한 번 열어 둔 앱은 계속 열립니다.

**바탕화면 아이콘 만들기**
- **Edge**: 주소를 연 뒤 오른쪽 위 `…` → **앱** → **이 사이트를 앱으로 설치** → 설치 후 나오는 창에서 **바탕 화면에 바로 가기 만들기**를 체크합니다.
- **Chrome**: 주소창 오른쪽의 설치 아이콘(모니터 모양), 또는 `⋮` → **전송, 저장, 공유** → **바로가기 만들기** → **창으로 열기**를 체크합니다.
- 저장소에 있는 **`내 캘린더.url`** 파일을 바탕화면에 복사하면 바로 아이콘이 됩니다.
- 설치가 막혀 있으면: 바탕화면 빈 곳을 우클릭 → **새로 만들기 → 바로 가기** → 위 주소를 붙여넣고 이름을 `내 캘린더`로 정합니다.

### A-2. 파일 하나로 쓰기 (설치·인터넷 배포 없이, 회사 PC)
`npm run build:single`을 실행하면 `dist-single/index.html` 파일 **하나**에 앱 전체가 들어갑니다.
- 이 파일을 `내 캘린더.html`로 이름을 바꿔 문서 폴더 같은 곳에 두고 더블클릭하면 브라우저에서 바로 열립니다.
- 바탕화면 아이콘: 파일을 우클릭 → **보내기 → 바탕 화면에 바로 가기 만들기**를 누른 뒤, 바로 가기의 **속성 → 아이콘 변경**에서 `public/icon.ico`를 고릅니다.
- 데이터는 그 브라우저에 저장되고, 새로고침하거나 브라우저를 다시 열어도 남아 있습니다.

### B. 내 PC에서 직접 실행 (Node.js 필요)
폴더 안의 **`내 캘린더 실행.cmd`** 를 더블클릭합니다. 첫 실행 때만 필요한 파일을 내려받습니다.

터미널로 직접 실행할 때는 **한 줄씩 따로** 입력합니다. Windows PowerShell 5에서는 `&&`가 안 됩니다.
PowerShell에서 "스크립트를 실행할 수 없습니다" 오류가 나면 `npm` 대신 `npm.cmd`를 씁니다.
```bat
cd calendar-app
npm.cmd install
npm.cmd run dev
```

### C. 개발용 (Mac / Linux / Git Bash)
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 정적 파일 생성
```

> ⚠️ 일정 데이터는 **각 브라우저의 각 주소마다 따로** 저장됩니다. 그래서 A(github.io)와 B(localhost)의 데이터는 서로 보이지 않습니다.
> 옮기려면 사이드바 아래 **내보내기**로 JSON 파일을 받은 뒤, 다른 쪽에서 **백업 열기**로 불러옵니다.

## GitHub Pages 배포 설정 (처음 한 번)
1. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
2. 그다음부터는 `main` 브랜치에 push할 때마다 `.github/workflows/deploy.yml`이 자동으로 빌드하고 배포합니다.
3. 배포 주소는 **Actions** 탭의 실행 결과나 **Settings → Pages**에서 확인합니다.

GitHub Pages는 무료 계정이면 **공개 저장소에서만** 쓸 수 있습니다. 비공개 저장소에서 쓰려면 GitHub Pro 이상이 필요합니다.
일정 데이터와 API 키는 저장소에 올라가지 않고 각자의 브라우저에만 있습니다. 그래서 코드를 공개해도 개인 데이터는 노출되지 않습니다.

## 기능
- 월 / 주 / 일 보기, 오늘 이동, 이전·다음 이동, 사이드바 미니 달력
- 일정: 빈 칸을 클릭하면 1시간 일정, 드래그하면 원하는 길이로 생성됩니다. 블록을 끌어 옮기고 아래쪽 가장자리를 끌어 길이를 바꿉니다. 종일 칸이나 월간 칸을 더블클릭하면 종일 일정이 생깁니다.
- 할 일: 체크, 마감일, 우선순위, 태그. 사이드바에 오늘 / 인박스 / 예정 / 완료됨 / 태그별 목록이 있습니다.
- **타임 블로킹**: 사이드바의 할 일을 주·일 보기의 시간 칸에 끌어다 놓으면 30분 블록이 됩니다. 종일 칸이나 월간 칸에 놓으면 마감일이 바뀝니다.
- 상세 패널(오른쪽 사이드 피크): 제목, 속성 표, 메모가 있고 자동 저장됩니다. 메모 줄 맨 앞에서 `/`를 누르면 블록 메뉴가 열립니다.
- 한국어 빠른 입력: `내일 3시 치과 #건강 !높음`, `다음주 금요일 오후 2시~4시 회의`, `11월 30일 보고서 마감`
- 커맨드 팔레트(Ctrl/⌘+K): 검색, 새 일정 / 새 할 일(자연어), 보기 전환
- JSON 내보내기·가져오기(백업), 다크 모드, 모바일 레이아웃
- **캡처로 일정 추가**: 스크린샷, 사진, PDF, 텍스트, .ics 파일에서 일정을 찾아 줍니다. 아래 사용법을 보세요.

## 캡처·파일로 일정 추가
1. 화면을 캡처한 뒤 앱에서 **Ctrl/⌘+V**를 누릅니다. 파일을 화면에 끌어다 놓거나, 툴바의 **캡처로 추가** 버튼(단축키 `I`)을 눌러도 됩니다.
2. **일정 찾기**를 누르면 Claude가 이미지와 PDF를 읽고 일정과 할 일을 뽑아냅니다.
3. **검토 화면**에서 원본 이미지와 나란히 비교하면서 모든 칸을 바로 고칠 수 있습니다.
   - 노란 칸: AI가 확신하지 못한 값입니다(흐린 글씨, 추측한 시간 등). 이유가 함께 표시되고, 값을 고치거나 **맞아요**를 누르면 사라집니다.
   - 빨간 칸: 저장할 수 없는 오류입니다(제목 없음, 종료가 시작보다 빠름, 날짜 형식 오류). 고치거나 선택을 해제해야 추가 버튼이 켜집니다.
   - 같은 날 같은 제목의 항목이 이미 있으면 중복으로 보고 선택을 미리 해제해 둡니다.
   - 항목마다 근거가 된 원문이 표시되고, 일정/할 일 전환, 삭제, 직접 추가가 됩니다.
4. **선택한 N개 추가**를 누르면 캘린더에 들어갑니다.

AI 분석에는 **Claude API 키**가 필요합니다. 사이드바 아래 ⚙ 또는 가져오기 창의 **설정**에서 넣으세요.
키는 이 브라우저의 localStorage에만 저장되고 Anthropic API로만 전송되므로, 공용 컴퓨터에서는 쓰지 마세요.
기본 모델은 Claude Opus 5.5이고, 설정에서 Sonnet 5.5나 Haiku 5.5로 바꿀 수 있습니다.
키가 없어도 `.ics` 파일과 한 줄에 하나씩 적은 텍스트(빠른 입력 문법)는 가져올 수 있습니다.

## 표·보드 보기 (노션 데이터베이스처럼)
제목 아래 탭에서 **캘린더 / 표 / 보드**를 고릅니다. 단축키는 `L` 표, `B` 보드, `M/W/D` 캘린더입니다. 모두 같은 데이터를 쓰므로 어디서 바꿔도 다른 보기에 바로 반영됩니다.
- **표**: 제목, 유형, 날짜, 상태, 우선순위, 태그, 수정일
  - 열 제목을 누르면 정렬하고, 한 번 더 누르면 반대 방향으로 정렬합니다.
  - 상태와 우선순위는 칸에서 바로 바꿉니다.
  - 맨 아래 **새로 만들기** 칸에도 빠른 입력 문법을 그대로 쓸 수 있습니다.
- **보드**: **상태별**(할 일 / 진행 중 / 완료) 또는 **우선순위별**로 묶습니다.
  - 카드를 다른 칸으로 끌어다 놓으면 상태나 우선순위가 바뀝니다.
  - 칸마다 아래에 **새로 만들기**가 있습니다.
- **필터**(표·보드 공통): 검색, 유형(표), 기간(오늘 / 이번 주 / 이번 달 / 지난 항목 / 날짜 없음), 우선순위, 태그, 완료 숨기기. 고른 보기와 필터는 브라우저가 기억합니다.
- 반복 항목은 **오늘 또는 다음 회차** 하나로 보입니다. 반복 할 일은 "할 일"과 "완료"만 쓸 수 있습니다(회차마다 완료를 따로 기록하기 때문).

## 하루: 아침 계획 · 하루 정리 · 주간 리뷰
보기 탭에서 **하루**를 누르거나 `P`를 누릅니다. 오후 3시 전에는 아침 계획이, 그 뒤에는 하루 정리가 먼저 열립니다.
- **아침 계획**
  - **어제까지 못 끝낸 일**: [오늘] [내일] [인박스]로 옮깁니다. **모두 오늘로**로 한 번에 옮길 수도 있습니다.
  - **인박스 정리**: 날짜 없는 할 일을 [오늘] 또는 [내일]로 보냅니다.
  - **오늘 할 일**: 오른쪽 오늘 시간표로 끌어다 놓으면 시간 블록이 됩니다. 일정과 시간 블록이 9시간 중 얼마나 차는지 막대로 보여 줍니다.
  - **오늘 계획 확정**을 누르면 지금 목록이 그날의 계획으로 기록됩니다.
- **하루 정리**
  - 완료율(계획한 일 중 끝낸 비율), 끝낸 일(계획 밖 포함), 집중 시간(끝낸 시간 블록 / 계획한 시간 블록), 일정
  - 계획 대비 결과 목록에서 못 끝낸 일을 [내일로] 보냅니다. 반복 할 일은 옮기지 않습니다.
  - 오늘 회고: 기분(5단계), 한 줄 회고, 잘한 점, 아쉬운 점. 입력하는 대로 저장됩니다.
  - **⭐ 내일 가장 중요한 일**에 적으면 내일 할 일(우선순위 높음)로 추가됩니다.
  - ‹ › 버튼으로 지난 날짜의 정리도 볼 수 있습니다.
- **주간 리뷰**
  - 끝낸 일, 평균 완료율, 집중 시간, 평균 기분
  - 요일별 기분, 완료율, 한 줄 회고. 누르면 그날의 하루 정리로 갑니다.
  - 많이 한 태그, 이번 주 회고(잘한 점 / 다음 주에 바꿀 점)
- 회고와 계획 기록도 **GitHub 동기화**와 **내보내기 백업**에 포함됩니다.

## 템플릿
자주 반복하는 할 일 묶음을 저장해 두고 원하는 날짜에 한 번에 넣습니다. 사이드바 **템플릿 +**에서 만들거나 고릅니다.
- **두 종류**
  - **할 일 묶음**: 출근 루틴, 회의 준비처럼 고른 날짜에 넣습니다.
  - **프로젝트째**: 이사 준비, 여행 준비처럼 넣을 때 새 프로젝트를 만들고, 마감일을 기준으로 날짜를 계산합니다.
- **글 형식** (한 줄에 할 일 하나, 빠른 입력 문법 그대로)
  ```
  07:00-07:20 스트레칭 #건강          ← 기준일에, 시간 블록으로
  +1 주간 보고서 쓰기 !높음            ← 다음 날
  D-7 전입신고 서류 준비               ← 기준일(마감일) 7일 전
    - 신분증                          ← 들여쓴 '- ' 줄은 하위 할 일
  // 메모                             ← 무시
  ```
  템플릿 안에서는 "오늘", "내일" 같은 말이 날짜로 해석되지 않고 제목에 그대로 남습니다.
- **넣기**: 날짜(프로젝트는 마감일)를 고르면 각 할 일이 언제 들어갈지 미리 보여 줍니다. 필요 없는 줄은 체크를 빼면 됩니다.
- **예시**: 출근 루틴, 주간 회의 준비, 이사 준비, 여행 준비. 그대로 쓰거나 고쳐서 저장합니다.
- 프로젝트 화면 아래 **템플릿으로 저장**을 누르면 지금 프로젝트를 템플릿으로 만듭니다(마감일 기준 D-n으로 변환).
- 템플릿도 GitHub 동기화와 백업에 포함됩니다.

## 휴대폰에서 쓰기
- **아래 탭 바**: 캘린더 · 할 일 · 보드 · 하루 · 습관. 프로젝트, 템플릿, 구독, 설정은 왼쪽 위 ☰에서 엽니다.
- **+ 버튼**: 아래에서 빠른 추가 창이 올라옵니다. 할 일과 일정 중 고르고, 빠른 입력 문법으로 연달아 적을 수 있습니다.
- **캘린더**
  - 일정을 **길게 눌러**(진동) 끌면 옮겨지고, 빈 칸을 길게 눌러 끌면 새 일정이 생깁니다. 그냥 밀면 스크롤됩니다.
  - 짧게 누르면 일정이 열리고, 빈 칸을 짧게 누르면 1시간 일정이 생깁니다.
  - 화면을 **좌우로 쓸면** 이전·다음 날로 넘어갑니다.
- **보드**: 손가락으로는 끌어다 놓기가 안 되므로, 카드의 **옮기기 ▸**로 다른 칸에 보냅니다.
- **뒤로가기 버튼**: 열린 상세 화면, 창, 사이드바를 닫습니다(앱 밖으로 나가지 않음).
- 체크박스 주변까지 눌리고, 입력칸을 눌러도 화면이 확대되지 않습니다(iOS). 홈 화면에 추가하면 앱처럼 열립니다.

### 화면 크기에 맞춰 자동으로 바뀌는 배치 (반응형)
| 화면 | 너비 | 사이드바 | 상세 패널 |
|---|---|---|---|
| 휴대폰 | 768px 미만 | ☰로 여는 덮개 | 화면 전체 |
| 태블릿·작은 노트북 | 768~1199px | ☰로 여는 덮개 | 오른쪽에서 밀려 나오는 서랍(캘린더가 줄지 않음) |
| PC | 1200px 이상 | 옆에 고정, 너비 조절 | 옆에 고정, 너비 조절 |

- 휴대폰에서는 머리글을 한 줄(☰ · 제목 · ‹ 오늘 › · 월/주/일)로 줄였습니다. AI 비서·사진으로 추가는 **+ 버튼** 창 안에 있습니다.
- 시간 칸은 `오전 9`, `오후 1`처럼 짧게 표시하고, 보드·표의 검색·필터·그룹 줄은 넘치면 옆으로 밉니다.
- 그래도 크게 느껴지면 설정 → **화면** 탭에서 화면 전체 크기를 80~90%로 줄이세요(기기마다 따로 기억).

## 화면 크기 조절
- **사이드바 / 상세 패널 너비**: 경계선을 끌어서 바꿉니다. 경계선을 두 번 누르면 기본값으로 돌아갑니다.
- **보드 칸 너비**: 각 칸 오른쪽 경계를 끌어서 칸마다 따로 바꿉니다(상태별·우선순위별·프로젝트별로 따로 기억).
- **화면 전체 크기(80~140%)**: 설정 → **화면** 탭. 글자, 버튼, 칸이 함께 커지거나 작아집니다.
- **캘린더 시간 칸 높이**: 설정 → 화면 탭, 또는 주·일 보기에서 **Ctrl(⌘) + 마우스 휠**.
- 모두 이 브라우저에 기억됩니다(기기마다 따로).

## 습관 기록
**반복 할 일**이 곧 습관입니다. 보기 탭의 **습관**(단축키 `H`)에서 봅니다.
- **오늘의 습관**: 오늘 해야 할 습관 체크리스트와 연속 기록 🔥. 체크하면 "🔥 22일 연속!"을 알려 줍니다.
- **최근 26주 히트맵**: 그날 해야 했던 습관 중 몇 개를 했는지 진하기로 보여 줍니다.
- **습관별 카드**: 지금 연속 기록(회차 기준이라 월·수·금 습관은 그 요일만 셉니다), 최고 기록, 30일 달성률, 총 횟수, 습관별 히트맵. **지난 칸을 누르면** 그날 체크를 채우거나 지울 수 있습니다.
- **새 습관**: "매일 아침 7시 스트레칭", "평일 영어 단어 20개", "매주 월 수 금 러닝"처럼 적습니다. 반복을 적지 않으면 매일로 만듭니다.
- 사이드바 할 일 줄에 🔥 연속 기록이, 주간 리뷰에 **이번 주 습관** 표(● 함 / ✕ 못 함 / ○ 남음)가 보입니다.
- 오늘 회차를 아직 안 했으면 연속 기록은 어제까지로 셉니다(오늘 안에 하면 이어집니다). 완료 기록은 3년치를 보관합니다.

## 기념일·D-day
왼쪽 사이드바 **기념일·D-day**의 **+**로 추가합니다(Ctrl+K → "기념일"도 됨).
- **매년 돌아오는 날**(생일·결혼기념일): 다음 날짜까지 D-day를 세고, 태어난 해를 넣으면 "31번째"처럼 보여 줍니다. **음력**에 체크하면 음력 월·일로 해마다 양력 날짜를 계산합니다. 연도를 모르면 **연도 모름**에 체크하세요.
- **한 번뿐인 날**(시험·여행·만난 날): 다가오면 D-12, 지나면 D+30 (시작한 날을 1일로 "31일째")으로 보여 줍니다.
- 캘린더(월·주·일)에 종일 일정처럼 보이고, 누르면 편집 창이 열립니다. 7일 안에 다가오면 사이드바에 빨갛게 표시되고 **아침 브리핑**에도 나옵니다.
- 일정처럼 GitHub 동기화로 다른 기기에도 똑같이 보입니다.

## 엑셀(CSV) 내보내기
사이드바 맨 아래 **내보내기**(또는 Ctrl+K → "엑셀")에서 기간(이번 주·이번 달·지난달·올해·직접)과 일정/할 일, 완료 포함 여부, 프로젝트를 고르면 CSV 파일로 저장합니다. 엑셀에서 바로 열리고 한글이 깨지지 않습니다.
- 열: 유형, 제목, 날짜, 요일, 시작, 종료, 시간(분), 종일, 마감일, 상태, 우선순위, 프로젝트, 태그, 메모, 완료한 때, 캘린더, 반복
- 반복 일정은 기간 안의 회차마다 한 줄씩 나옵니다.
- 같은 창의 **전체 백업(JSON) 저장**은 예전 "내보내기"와 같습니다(다른 기기에서 "백업 열기"로 되살리기).

## 월간 리포트 (업무 통계)
**하루** 탭 → **월간 리포트**. ‹ › 로 달을 넘깁니다.
- 완료한 할 일, 집중 시간, 일정 수·시간, 습관 달성률을 지난달과 비교해서 보여 줍니다.
- 날짜별 완료(또는 집중 시간) 막대그래프 — 막대에 마우스를 올리면 값이 보입니다.
- 프로젝트별 진행률·이번 달 완료·집중 시간, 태그별로 쓴 시간, 마감이 지났는데 못 끝낸 일.
- **보고용 글 복사**를 누르면 "■ 11월 업무 리포트 · 완료한 할 일 …" 형식의 글이 복사되어 메일·메신저·보고서에 바로 붙여넣을 수 있습니다. **엑셀로**는 그달 기준 CSV 내보내기를 엽니다.

## 음성으로 추가
입력칸 옆 🎤 버튼을 누르고 말하면 글자로 채워집니다. 예: "내일 오후 3시 거래처 미팅". 확인하고 **추가**를 누르세요.
- 휴대폰 **+ 빠른 추가**, 사이드바 **할 일 추가**, **AI 채팅** 입력칸에 있습니다. Ctrl+K → "말로 추가"도 됩니다.
- 브라우저 내장 음성 인식이라 요금은 없습니다(Chrome·Edge·Safari·안드로이드 크롬). 처음 한 번 마이크 권한을 허용해야 합니다. 브라우저에 따라 음성이 구글·애플 서버에서 글자로 바뀝니다. Firefox는 지원하지 않아 버튼이 보이지 않습니다.

## 홈 화면 바로가기 메뉴
홈 화면에 추가한(설치한) 앱 아이콘을 **길게 누르면**(PC는 작업 표시줄 아이콘 우클릭) 바로가기가 뜹니다.
- **할 일 추가** · **말로 추가** · **오늘 브리핑** · **AI 채팅**
- 안드로이드 크롬, Windows의 Edge/Chrome 설치 앱에서 됩니다. 아이폰(사파리)은 아직 이 기능을 지원하지 않습니다.
- 이미 설치했다면 바로가기가 생기기까지 앱을 한두 번 열어야 할 수 있습니다(안 생기면 앱을 지웠다가 다시 홈 화면에 추가).
- 주소로도 됩니다: `…/my-calendar/?action=add` (add · voice · briefing · chat · dday · export)

## 한국 공휴일
캘린더(월·주·일 보기, 왼쪽 작은 달력)에 공휴일을 **빨간 날**과 이름으로 보여 줍니다. 모든 달력 화면에서 **일요일·공휴일은 빨간색, 토요일은 파란색, 오늘은 초록색**이고, 공휴일 칸에는 옅은 붉은 배경이 깔립니다.
- 신정, 설날 연휴, 삼일절, 어린이날, 부처님오신날, 현충일, 광복절, 추석 연휴, 개천절, 한글날, 성탄절
- **설날·추석·부처님오신날**은 브라우저에 내장된 한국 음력(단기력)으로 해마다 자동 계산합니다.
- **대체공휴일**도 규정대로 자동 계산합니다. 설·추석은 일요일이나 다른 공휴일과 겹칠 때, 어린이날·국경일·부처님오신날·성탄절은 토·일·다른 공휴일과 겹칠 때 다음 평일이 대체공휴일이 됩니다.
- **선거일·임시공휴일**은 이미 알려진 것만 들어 있습니다(2024~2026년, 2028 총선). 새로 지정되면 설정 → **화면** 탭 → **직접 추가한 휴일**에 넣으세요. 회사 창립기념일이나 여름휴가도 같은 곳에 넣으면 됩니다(이 기기에만 저장).
- 노동절·제헌절처럼 쉬지 않는 기념일은 회색으로 표시합니다(끌 수 있음).
- 아침 브리핑에 "🎉 오늘은 ○○" 이 붙고, **평일만**으로 해 두면 공휴일에도 브리핑을 쉽니다. AI 채팅도 일정을 찾을 때 공휴일을 함께 봅니다.
- 끄려면 설정 → **화면** 탭 → **한국 공휴일 표시**.

## 아침 브리핑
설정 → **알림** 탭 → **아침 브리핑**을 켜고 시각을 정하면, 그 시각이 지나 앱을 처음 볼 때 오늘 하루 요약 창이 뜹니다(하루 한 번, 오후 3시까지).
- **오늘 일정**(구독 캘린더 포함), **밀린 할 일**, **오늘 할 일**·진행 중, **오늘의 습관**, **곧 마감(3일 안)**, **이번 주 마감 프로젝트**를 한눈에 보여 줍니다.
- 창 안에서 바로 체크해 완료할 수 있고, 항목을 누르면 상세가 열립니다. **아침 계획 세우기**를 누르면 하루 → 아침 계획으로 갑니다.
- 앱이 다른 탭에 있거나 최소화돼 있으면 시스템 알림으로 알려 주고, 누르면 브리핑이 열립니다. 앱이 완전히 닫혀 있으면 알림이 오지 않고, 다음에 열 때 브리핑이 뜹니다.
- **평일만** 옵션으로 주말엔 쉴 수 있습니다.
- **AI 한마디**(선택): Claude가 먼저 챙길 일과 짧은 조언을 3~5문장으로 써 줍니다. **날씨 도시**를 넣으면 웹 검색으로 그날 날씨도 넣어 줍니다. 하루 한 번만 만들고 저장해 두므로 다시 열어도 요금이 더 들지 않습니다(**다시 만들기**를 누를 때만 다시 만듦).
- 언제든 보려면: 하루 → 아침 계획의 **☀️ 브리핑** 버튼, 또는 Ctrl+K → "아침 브리핑".
- 설정은 기기(브라우저)마다 따로입니다.

## AI 채팅 (웹 검색 · 무엇이든 질문)
위쪽 **AI 채팅** 탭(단축키 **C**, 휴대폰은 아래 **AI** 탭)에서 Claude와 대화합니다. 일정과 상관없는 질문도 됩니다.
- **웹 검색**: 뉴스, 날씨, 가격, 영업시간처럼 바뀌는 정보는 알아서 검색하고, 답 아래에 **출처** 링크를 붙입니다. 링크를 붙여넣으면 그 페이지를 읽고 요약합니다.
- **사진·PDF·텍스트 첨부**: 🖼 버튼이나 붙여넣기(Ctrl+V)로 올리면 내용을 읽고 답합니다.
- **내 캘린더 확인**: "이번 주 일정 정리해줘"처럼 물으면 내 일정·할 일(반복, 구독 캘린더 포함)을 직접 찾아보고 답합니다.
- **캘린더에 바로 넣기**: "다음 주 금요일 7시 저녁 약속 넣어줘" → 바로 추가하고, 채팅에 **되돌리기** 카드가 남습니다. "○○ 끝냈어"라고 하면 할 일을 완료로 표시합니다.
- **대화 기록**은 이 기기(브라우저)에만 저장되고 동기화되지 않습니다. 목록에서 지울 수 있습니다.
- 대화가 길어질수록 앞 내용을 다시 보내므로 비용이 늘어납니다. 주제가 바뀌면 **새 대화**를 시작하세요. 입력칸 아래에 이 대화에서 쓴 토큰과 검색 횟수가 보입니다. (웹 검색은 1,000회당 약 $10이 추가로 청구됩니다.)
- 설정 → AI 탭의 API 키와 모델을 그대로 씁니다. 여러 날짜에 걸친 일정 배치는 **AI 비서**가 더 알맞습니다(제안을 검토한 뒤 적용).

## AI 일정 비서
툴바의 **AI 비서**(단축키 `A`)를 누르고 말로 부탁하면, 빈 시간을 찾아 일정·시간 블록을 **제안**합니다. 적용하기 전에 검토하고 고칠 수 있습니다.
- 예: "다음 주 빈 시간에 운동 3번 넣어줘 (저녁에)", "이번 주 마감인 할 일들을 시간표에 배치해줘", "금요일 오후 일정을 다음 주로 미뤄줘"
- **동작 방식**: 앱이 오늘부터 21일 동안의 빈 시간(내 일정, 시간 블록, 구독 캘린더를 뺀 시간)을 직접 계산해서, 할 일 목록·마감일·우선순위·프로젝트와 함께 Claude에 보냅니다. 반복·구독·지난 일정은 '옮기지 말 것'으로 표시됩니다.
- **제안의 종류**: 새 일정·할 일 만들기, 기존 할 일에 시간 블록 배치, 기존 항목 옮기기, 마감일 변경
- **검토 화면**
  - 날짜별로 묶어 보여 줍니다. 날짜·시간·제목·프로젝트를 고칠 수 있고, 제안마다 선택하거나 뺄 수 있습니다.
  - 기존 일정이나 다른 제안과 **겹치면 노란 경고**가 뜹니다(그래도 적용할 수 있습니다).
  - 옮길 수 없는 항목은 자동으로 빠집니다.
- **이어서 요청**: "운동은 아침으로 바꿔줘"처럼 고쳐 달라고 하면 이전 제안을 바탕으로 다시 짭니다. 비서가 확인 질문을 하면 같은 칸에 답합니다.
- **적용 후**: 주간 보기로 이동하고, **되돌리기** 한 번으로 적용하기 전 상태로 돌아갑니다.
- 일정을 넣어도 되는 시간(기본 09:00–21:00)은 비서 창에서 바꿀 수 있습니다. **캡처로 추가**와 같은 Claude API 키를 쓰며, 할 일·일정의 제목과 시간이 Anthropic API로 전송됩니다.

## 프로젝트와 하위 할 일
- **프로젝트 만들기**: 사이드바 **프로젝트 +**를 누르면 노션 페이지 같은 프로젝트 화면이 열립니다.
  - 아이콘, 이름, 상태(진행 중/완료), 마감일(D-day), 색상, 설명
  - 진행률: 반복 할 일을 뺀 할 일 기준이고, 지난 할 일 수와 집중 시간 ⏱도 함께 보여 줍니다.
  - 할 일은 진행 중 / 할 일 / 완료로 묶어서 보여 줍니다. 다가오는 일정도 모아 보여 줍니다.
- **할 일을 프로젝트에 넣는 방법**
  - 프로젝트 화면에서 바로 추가
  - 빠른 입력에 `@이사`처럼 적기(이름 앞부분만 적어도 되고, 띄어쓰기는 무시합니다. 못 찾으면 제목에 그대로 남습니다)
  - 상세 화면의 **프로젝트** 속성에서 고르기
  - 보드를 **프로젝트별**로 묶은 뒤 카드를 끌어다 놓기
  - 표의 **프로젝트** 칸에서 바꾸기
- **하위 할 일**: 상세 화면의 "하위 할 일"에 체크리스트를 만듭니다. Enter를 누르면 아래에 새 줄이 생기고, 빈 줄에서 Backspace를 누르면 그 줄이 지워집니다. 사이드바, 표, 보드, 프로젝트 화면에 `☑ 1/3`처럼 진행 상황이 보입니다.
- 사이드바 프로젝트 목록에 진행률(%)이 보이고, 완료한 프로젝트는 접어 둡니다. 프로젝트 마감일은 캘린더 종일 칸에 표시되고, 누르면 프로젝트 화면으로 갑니다.
- 표·보드 필터에서 프로젝트로 거를 수 있습니다. 프로젝트를 지우면 안의 할 일과 일정은 그대로 남습니다.

## 집중 타이머 (포모도로)
- **시작하는 곳**: 상세 화면 위쪽의 **▶ 집중**, 사이드바·아침 계획 할 일 줄의 ▶(마우스를 올리면 보임), 툴바의 **⏱ 집중** 버튼(15/25/45/50분 바로 시작), `F` 키(열려 있는 항목에 집중하거나, 도는 중이면 일시정지/계속)
- 오른쪽 아래 타이머: 남은 시간, 진행 막대, 일시정지, 끝내기(기록), 작게 접기. 탭 제목과 툴바에도 남은 시간이 보입니다.
- 집중이 끝나면 소리와 알림이 울리고, 휴식(5분, 4번마다 15분)이 자동으로 시작됩니다. **"이 할 일을 끝냈나요? [완료]"**로 바로 체크할 수 있습니다.
- **기록되는 것**
  - 멈춘 시간을 뺀 실제 집중 시간만 저장합니다. 1분 미만은 버립니다.
  - 새로고침하거나 다른 탭에 가도 타이머는 이어집니다.
- **기록을 보는 곳**
  - 하루 정리의 **집중 시간 ⏱**(계획한 시간 블록과 비교)과 항목별 ⏱
  - 주간 리뷰의 요일별 ⏱와 합계
  - 캘린더 칸 오른쪽의 빨간 막대(실제로 집중한 시간대)
  - 상세 화면의 **집중 기록**(합계와 목록, 기록 지우기)
- 설정(타이머 창의 "타이머 설정"): 집중·휴식 길이, 긴 휴식 간격, 휴식 자동 시작, 소리
- 기록은 GitHub 동기화와 내보내기 백업에 포함됩니다.

## 구독 캘린더 (회사·구글·아웃룩 캘린더 함께 보기)
다른 캘린더의 **iCal(.ics) 주소**를 넣으면 내 캘린더 위에 **읽기 전용**으로 함께 보입니다. 사이드바의 **구독 캘린더 +** 또는 설정 → **구독 캘린더** 탭에서 추가합니다.
- **주소 찾기**
  - Google: 설정 → 캘린더 선택 → 캘린더 통합 → **iCal 형식의 비공개 주소**
  - Outlook / Microsoft 365: 설정 → 캘린더 → 공유 캘린더 → **캘린더 게시** → ICS 링크
  - iCloud: 공개 캘린더의 `webcal://` 링크
- 반복 회의(매주·매월 n번째 요일 등), 빠진 회차, 시간이 바뀐 회차, 취소된 회차, 시간대(Windows 시간대 이름 포함)를 반영합니다.
- 구독 일정은 끌어서 옮길 수 없습니다. 눌러서 내용(장소, 링크)을 보고, **내 일정으로 복사**할 수 있습니다.
- 사이드바에서 캘린더 이름을 누르면 보이기/숨기기가 바뀝니다. 아침 계획의 하루 부하에도 회의 시간이 반영됩니다.
- **GitHub 자동 가져오기**
  - 구글·아웃룩 주소는 보안 정책(CORS) 때문에 브라우저가 직접 읽지 못합니다.
  - 대신 **비공개 데이터 저장소**에 GitHub Actions 작업(`.github/workflows/fetch-calendars.yml`)을 만듭니다. 이 작업이 2시간마다, 그리고 구독 목록이 바뀔 때마다 `.ics`를 받아 `subscriptions/` 폴더에 저장하고, 앱은 그 파일을 읽습니다. 외부 서버를 거치지 않습니다.
  - 켜려면 동기화 토큰에 **Workflows: Read and write** 권한을 추가한 뒤 **자동 가져오기 켜기**를 누릅니다.
  - 구독 목록(`subscriptions.json`)도 저장소에 저장되어 다른 기기에 자동으로 나타납니다.
  - 비공개 저장소의 Actions 무료 사용량(월 2,000분) 안에서 동작합니다. 2시간마다 약 30초씩 실행됩니다.

## 반복 일정
- **만들기**: 빠른 입력이나 Ctrl/⌘+K에 이렇게 적으면 됩니다.
  `매주 월, 수 9시 스탠드업`, `격주 금요일 3시 1:1`, `평일 7시 30분 영어 공부`, `매일 밤 10시 일기 30회`,
  `매월 25일 월급날`, `매달 마지막 금요일 회식`, `매년 3월 1일 엄마 생신`, `매주 화 6시 필라테스 12월 31일까지`
- 상세 화면의 **반복** 속성에서도 바꿀 수 있습니다: 매일/매주/매월/매년, n일·주·개월·년마다, 요일 선택, 매월 같은 날짜 또는 n번째(마지막) 요일, 종료(계속 / 날짜까지 / 횟수)
- 반복 회차의 **날짜·시간을 바꾸거나 지우면** 범위를 묻습니다: **이 일정만 / 이 일정과 이후 일정 / 모든 일정**. 캘린더에서 드래그할 때도 똑같이 묻습니다.
- 제목·태그·메모·색상·알림은 모든 회차에 적용됩니다. 한 회차만 다르게 하려면 **이 회차만 따로 수정**을 누릅니다.
- 반복 할 일은 회차마다 완료 체크가 따로 저장됩니다(예: 매일 습관 체크).

## 알림
- 설정 → **알림** 탭에서 **알림 켜기**를 누르고 브라우저가 묻는 알림 권한을 허용합니다.
- 새 일정에는 기본 알림이 붙습니다(기본값: 시간 있는 일정 10분 전, 종일 일정 없음). 설정에서 바꿀 수 있습니다.
- 항목마다 상세 화면의 **🔔 알림**에서 추가하거나 뺍니다.
  - 시간 있는 일정: 시작할 때, 5·10·15·30분 전, 1·2시간 전, 하루 전
  - 종일 일정과 마감일: 당일 오전 8·9시, 전날 오전 9시, 2일 전 오전 9시
- 알림은 **앱이 열려 있을 때** 울립니다(최소화하거나 다른 탭에 있어도 됨). 서버 없이 동작하는 앱이라서, 브라우저를 완전히 닫으면 울리지 않습니다. Edge의 **앱으로 설치**로 띄워 두는 것을 추천합니다.
- 알림을 누르면 앱이 앞으로 오고 해당 일정이 열립니다. 앱을 늦게 열었다면 15분 이내에 지난 알림은 그때 보내 줍니다.

## 여러 기기에서 같은 일정 쓰기 (GitHub 비공개 저장소 동기화)
일정을 GitHub **비공개** 저장소의 `calendar.json` 파일에 저장해서, 회사·집·휴대폰이 같은 데이터를 쓰게 합니다.

**처음 한 번 준비**
1. https://github.com/new 에서 **Private** 저장소를 만듭니다. 예: `my-calendar-data`. 이 앱 코드 저장소와는 **따로** 만드세요.
2. https://github.com/settings/personal-access-tokens/new 에서 Fine-grained 토큰을 만듭니다.
   - Repository access: **Only select repositories** → 위 저장소만 고릅니다.
   - Permissions → Repository permissions → **Contents: Read and write**
3. 앱 사이드바 아래 **동기화 꺼짐 · 설정하기**를 누르고, 저장소(`아이디/my-calendar-data`)와 토큰을 넣은 뒤 **동기화 켜기**를 누릅니다.
4. 다른 기기에서도 앱을 열고 같은 값을 넣습니다.

**동작 방식**
- 앱을 열 때, 창으로 돌아올 때, 인터넷이 다시 연결될 때, 5분마다, 그리고 무언가를 고치고 3초가 지나면 자동으로 동기화합니다. 사이드바의 상태 표시를 누르면 바로 동기화합니다.
- 처음 켤 때는 이 기기의 일정과 저장소의 일정을 **합칩니다**. 어느 쪽도 지워지지 않습니다.
- 같은 항목을 두 기기에서 고쳤다면 **나중에 고친 쪽**이 남습니다. 삭제도 다른 기기에 반영됩니다(삭제 기록은 180일 보관).
- 두 기기가 동시에 저장해서 부딪히면 자동으로 다시 받아서 합칩니다.
- 동기화할 때마다 커밋이 남습니다. 실수로 지웠다면 저장소의 `calendar.json` **History**에서 예전 내용을 받아 **백업 열기**로 되살릴 수 있습니다.
- 공개 저장소는 거부합니다. 토큰은 이 브라우저에만 저장되므로 공용 컴퓨터에서는 쓰지 마세요.
- 회사 네트워크가 `api.github.com`을 막고 있으면 동기화되지 않습니다. 이때도 앱은 그대로 쓸 수 있고, 연결되는 곳에서 다시 맞춰집니다.

## 구조
```
src/
  types.ts            데이터 모델 (Item: event | task)
  db.ts               Dexie(IndexedDB) + 생성·수정·삭제 + 백업
  store.ts            Zustand UI 상태 (보기, 날짜, 선택 항목 등)
  lib/date.ts         날짜 유틸 (월요일 시작, ko)
  lib/items.ts        캘린더 배치, 겹침 레이아웃, 섹션 필터
  lib/parse.ts        한국어 자연어 빠른 입력 해석
  lib/ai.ts           Claude API로 일정 추출 (구조화 출력, 필요할 때만 로드)
  lib/importFiles.ts  AI 설정 저장, 이미지 축소·PDF·텍스트 변환
  lib/drafts.ts       검토용 임시 항목, 검증, .ics·텍스트 해석, 중복 확인
  components/         Sidebar, MiniCalendar, TaskList, Toolbar,
                      TimeGrid(주/일), MonthView, PeekPanel, CommandPalette,
                      ImportDialog(가져오기·검토), SettingsDialog
```
디자인 토큰(색, 테두리, 태그 9색, 다크 모드)은 `src/index.css`의 CSS 변수에 모여 있습니다.
